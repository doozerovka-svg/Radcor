# Правила разработки и B2B UI дизайна (RADCOR-PRIM v16.0)

## 0. Обязательный аудит и активация скиллов (Skill First Policy)
- **Первичный аудит скиллов**: Перед обработкой абсолютно любого пользовательского запроса агент ОБЯЗАН изучить полный список всех доступных в системе скиллов (Skill Registry).
- **Пошаговая проверка применимости**: Перед выполнением каждого действия или этапа работы агент проверяет: *«Существует ли специализированный скилл под эту подзадачу (дизайн, архитектура, планирование, оптимизация и т.д.)?»*
- **Безальтернативность применения**: Если подходящий скилл найден — агент ОБЯЗАН активировать его, прочесть его `SKILL.md` через `view_file` и следовать его предписаниям ДО написания кода. Использование общих знаний вместо доступного скилла строго запрещено.

## 1. Отказ от эмодзи и строгость B2B интерфейса (Aesthetics Invariants)
- **Полный запрет на эмодзи**: В названиях категорий, фильтрах, кнопках и бейджах строго запрещено использовать эмодзи (🛢, ❄️, 🔧, 🌸, 🔴, 🟢).
- **Векторная графика**: Использовать исключительно тонкие однотонные SVG-иконки (`stroke: currentColor`, `stroke-width: 1.8 - 2.0`) с выравниванием по левому краю.
- **Разделители B2B-списков**: Пункты меню категорий и фильтров оформлять с выверенными отступами и разделителем `border-bottom: 1px solid #F0F2F5`.
- **CSS Color Swatches**: Для визуализации цвета жидкостей/антифризов использовать 10px кружки `.swatch-dot` с внутренней тенью `box-shadow: inset 0 0 0 1px rgba(0,0,0,0.15)`.

## 2. Неприкосновенность данных спецификаций и допусков OEM (Data Integrity)
- **100% Сохранность оригинальных строк допусков**: Запрещено модифицировать, автоматически расщеплять по запятым, менять регистр или обрезать официальные наименования допусков (`VW 504.00/507.00`, `MB 229.51`, `SAE J 1703, FMVSS 116`).
- **Отображение и поиск**: Текст допусков выводится в DOM в исходном виде. Поисковый индекс должен быть регистронезависимым и искать по подстроке без искажения оригинала.

## 3. Карточки товаров и выдвижные панели (Product Cards & Drawers)
- **Лицевая сторона карточки**: Отображает только Название, Описание (при наличии), **Вязкость** и **Класс**. Если данных по вязкости/классу нет — блок скрывается полностью.
- **Интерактивные кнопки к доп. данным**:
  - `[ SVG Допуски ]` — выводит оригинальный текст OEM-допусков.
  - `[ SVG Характеристики ]` — выводит физико-химические свойства.
- **Лаконичные панели `.product-card-drawer`**:
  - Запрещены крупный верхний заголовок, декоративные разделители и кнопка-крестик `×`.
  - Открытие происходит мгновенно, повторный клик или клавиша `Esc` сворачивает панель.
  - Активная кнопка подсвечивается классом `.active`.
  - Строки допусков выходят только по кнопке «Допуски» и не дублируются в «Характеристиках».

## 4. Иерархическая структура каталога (Catalog Hierarchy)
- **Актуальная схема категорий**:
  - `lubricants` — **Смазочные материалы** (родительская, аккордеон):
    - `motor-oils-pkw` — Легковые масла (PKW)
    - `motor-oils-lkw` — Грузовые масла (LKW)
    - `moto-oils` — Мото масла
    - `transmission-oils` — Трансмиссионные масла
    - `hydraulic-oils` — Гидравлические масла
    - `greases` — Смазки
    - `industrial-lubricants` — Промышленные смазочные материалы
  - `coolants` — Охлаждающие жидкости
  - `brake-fluids` — Тормозные жидкости
  - `auto-chemistry` — Автохимия и автокосметика
  - `accessories` — Аксессуары
  - `auto-lamps` — Автолампы (плейсхолдер)
- **Массив `LUBRICANT_SUBCATEGORIES`**: Находится в `app.js` и является единственным источником правды подкатегорий смазок.
- **Синхронизация и URL**: Клик по `lubricants` показывает товары всех подкатегорий. `init()` читает `?cat=` и открывает нужный раздел. При невалидном `?cat=` происходит мягкий fallback на `all`.

## 5. Товары без фиксированной цены (Price on Request)
- **Логика**: Категория `industrial-lubricants` и товары с `price_on_request: true` скрывают числовую цену.
- **Оформление**: Надпись «по запросу» (класс `.price-on-request`, цвет `#D97706`).
- **Действие**: Вместо кнопки «+ В заказ» выводится кнопка-ссылка «Запросить» (`.btn-call-request`), ведущая на `tel:+37368550595`.
- **Контакт**: В блоке `.product-price-unit` указывается телефон `+373 685 50 595`.

## 6. Правила добавления и миграции товаров (Product Migration)
- **Категоризация**: Разрешены только ключи из Раздела 4. Устаревшие ключи (`motor-oils`, `autochemistry`, `winter`, `industrial`) запрещены.
- **Cache Busting**: При любом обновлении `products.json`, `app.js` или `style.css` обязательно инкрементировать версию `?v=XX.X` во всех HTML-файлах.
- **Сохранность элементов**: Не удалять пустые категории-плейсхолдеры без прямого указания пользователя.
