# Правила разработки и B2B UI дизайна (RADCOR-PRIM)

## 1. Отказ от эмодзи и строгость B2B интерфейса (Aesthetics Invariants)
- **Полный запрет на эмодзи**: В названия категорий, боковое меню фильтров, кнопки и бейджи товаров строго запрещено вставлять эмодзи (например: 🛢, ❄️, 🔧, 🌸, 🔴, 🟢).
- **Минималистичные однотонные SVG-иконки**: Использовать только тонкие векторные SVG-иконки (`stroke: currentColor`, `stroke-width: 1.8 - 2.0`) с выравниванием по левому краю.
- **Разделители B2B-списков**: Пункты меню категорий и фильтров оформлять с мелкими отступами и разделителем `border-bottom: 1px solid #F0F2F5`.
- **CSS-образцы цветов (Color Swatches)**: Для фильтров и бейджей цвета (например, антифризы) применять аккуратные 10px кружки `.swatch-dot` с тонкой внутренней тенью (`box-shadow: inset 0 0 0 1px rgba(0,0,0,0.15)`).

## 2. Неприкосновенность данных спецификаций и допусков OEM (Data Integrity)
- **100% Сохранность оригинальных строк допусков**: Запрещено модифицировать, автоматически парсить, разделять по запятым или обрезать официальные наименования допусков и стандартов (например: `VW 504.00/507.00`, `SAE J 1703, FMVSS 116, DOT 3, ISO 4925 Class 3`, `MB 229.51, BMW Longlife-04`).
- **Отображение без искажений**: Текст допусков из базы данных или прайс-листа выводить в исходном виде.

## 3. Карточки товаров и выдвижные панели (Product Cards & Drawers)
- **Лицевая сторона карточки (Default View)**: Отображает только название товара, его описание (если есть), **Вязкость** и **Класс**. Если данных по вязкости/классу нет, мини-блок характеристик не выводится вовсе.
- **Интерактивные кнопки к доп. данным**:
  - `[ SVG Допуски ]` — выводит оригинальный текст допусков OEM.
  - `[ SVG Характеристики ]` — выводит физико-химические свойства товара.
- **Лаконичные панели без лишнего пространства**:
  - В панели `.product-card-drawer` не использовать крупный верхний заголовок (`«ПОЛНАЯ ИНФОРМАЦИЯ:»`), линии-разделители и кнопку-крестик `×`.
  - Информация показывается сразу после нажатия.
  - Повторный клик по той же кнопке сворачивает панель.
- **Исключение дублирования**: Строки допусков выводятся только по кнопке «Допуски» и не дублируются в списке «Характеристики».

## 4. Иерархическая структура каталога (Catalog Hierarchy)
- **Актуальная схема категорий (v15.0)**:
  - `lubricants` — **Смазочные материалы** (родительская, аккордеон):
    - `motor-oils-pkw` — Легковые масла (PKW)
    - `motor-oils-lkw` — Грузовые масла (LKW)
    - `moto-oils` — Мото масла
    - `transmission-oils` — Трансмиссионные масла
    - `hydraulic-oils` — Гидравлические масла
    - `greases` — Смазки
    - `industrial-lubricants` — Промышленные смазочные материалы
  - `coolants` — Охлаждающие жидкости
  - `brake-fluids` — Тормозные жидкости
  - `auto-chemistry` — Автохимия и автокосметика
  - `accessories` — Аксессуары
  - `auto-lamps` — Автолампы
- **Массив `LUBRICANT_SUBCATEGORIES`**: Подкатегории `lubricants` определены в `app.js`. При добавлении новой подкатегории обязательно обновить этот массив.
- **Фильтрация родительской категории**: Клик по `lubricants` должен показывать товары из ВСЕХ подкатегорий.
- **Аккордеон в боковом меню**: Подкатегории смазочных материалов скрыты за `.sidebar-cat-accordion` и раскрываются по стрелке. CSS-класс `.open` управляет видимостью `.sidebar-cat-sublist`.
- **URL-параметр `?cat=`**: `init()` в `app.js` читает `window.location.search` и активирует нужную категорию + раскрывает аккордеон для подкатегорий.

## 5. Товары без фиксированной цены (Price on Request)
- **Промышленные смазочные материалы** (`industrial-lubricants`) и любые товары с флагом `price_on_request: true` не отображают числовую цену.
- **Вместо цены**: Надпись «по запросу» (класс `.price-on-request`, цвет `#D97706`).
- **Вместо кнопки «+ В заказ»**: Ссылка-кнопка «Запросить» (класс `.btn-call-request`), ведущая на `tel:+37368550595`.
- **В карточке указывается**: контактный телефон `+373 685 50 595` в строке `.product-price-unit`.

## 6. Правила добавления и миграции товаров (Product Migration)
- **При добавлении нового товара**: Указывать корректный ключ категории из актуального списка (раздел 4). Старые ключи (`motor-oils`, `autochemistry`, `winter`, `industrial`) более не используются.
- **Cache busting**: После каждого обновления `products.json`, `app.js` или `style.css` — обязательно инкрементировать версию `?v=XX.X` во ВСЕХ HTML-файлах.
- **Удаление ненужных категорий запрещено без подтверждения**: Категории «Автолампы» и другие пустые разделы созданы намеренно как плейсхолдеры для будущих товаров.
